# 微信表情包处理工具

## 项目简介

微信表情包处理工具是一个用于处理和转换图片的应用程序。它支持多种格式的图片，并提供尺寸调整、格式转换、背景去除等功能。

## 安装步骤

1.  确保已安装Python 3.x。

1.  安装所需的Python库：

    bash

    复制

    ```
    pip install pillow
    ```

1.  下载或克隆项目代码到本地。

## 使用说明

1.  运行`sticker_tool.py`文件启动应用程序。
1.  使用界面选择图片文件，并根据需要调整尺寸、格式和背景。
1.  点击“处理图片”按钮进行处理，并选择保存位置。

## 功能列表

-   支持PNG、JPG、GIF、WEBP格式的图片。
-   提供多种尺寸调整选项。
-   支持背景去除功能。
-   支持批量处理多张图片。
